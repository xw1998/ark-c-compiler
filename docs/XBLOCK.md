# 整块重复块消除（`--xblock`）

> 0.9.1 的第四条优化，P1 `ir.tailmerge` 的整块形态。一句话：**两个基本块
> 逐条指令相同、入口栈为空、且只有一个出口写着去处，就只留一份，其余改成就地
> 一条跳转**。
>
> 实现位置：`src/opt_tailmerge.c`（IR pass，阶段 `ir.xblock`，与 `ir.tailmerge`
> 共用匹配器与栈深模型）
> 门禁：`tests/run_xblock_tests.py`（`make test-xblock`）
> 开关：`--xblock` / `--no-xblock`，INI `xblock=` / `cross-block=`

---

## 1. 和 `--tailmerge` 的关系

AC5 把「尾段合并」和「整块合并」放在同一个 `zip` 里，只有候选生成器不同。arkc 照这个
分法：`tm_same_inst()`（逐条指令比较）与 `tm_analyse_depth()`（逐块求值栈深度）是共享的，
`ir.tailmerge` 只比「块尾的相同后缀」，`ir.xblock` 比「整块」。两个阶段各有自己的运行期
开关和编译期宏，互不牵连——开一个不等于开两个。

## 2. 三条额外硬条件（各自对应一种错答案）

尾段合并天然满足这三条（尾段起始处栈必为空、尾段内不含标签、结尾必是 `return`），
整块合并必须显式检查，否则每一条都能安静地改掉程序的含义。

| 条件 | 不检查会怎样 |
| --- | --- |
| **a) 入口求值栈深度为 0** | 块可以从「栈上还压着半个表达式」的地方进入。跳到共用副本等于把求值栈跨控制流边搬运，没有任何后端承诺这件事。 |
| **b) 块体（跳过开头连续标签后）不含任何标签** | 每个标签都是别人的跳转目标。两份同名目标会变成「都落在先到的那一份上」，跳转去向被静默改写。 |
| **c) 块体以单后继控制转移收尾：`JMP` / `JMP_NAMED` / `RETURN`** | 见下。 |

### 2.1 为什么条件分支（`JZ` / `JNZ`）必须拒绝

`if` 形态的块以条件分支收尾时，**taken 后继写在块体里，fall-through 后继由块在指令表里的
位置决定**。两块块体一模一样，跌出去的地方却可能完全不同：

```c
int cond_case(int a, int b)
{
    int r = 0;
    if (a == 1)      { if (b * 2 > 10) { r = b + 1; } }   /* 跌到 r = b + 1 */
    else if (a == 2) { if (b * 2 > 10) { r = b + 2; } }   /* 跌到 r = b + 2 */
    return r;
}
```

两个 `if (b * 2 > 10)` 的条件块逐条相同、都以条件分支收尾。合并以后，`a == 1` 那条会
落进 `r = b + 2`。所以条件分支一律拒绝——只有**单后继、且后继写在块体里**时才允许合并。

### 2.2 跳转目标按「块」比较，不按 label id

`irgen` 给 `if` / `else if` 的每个分支各造一个合并点标签，于是两个分支的终结指令写的是
`.L_two_1` 与 `.L_two_3`——**同一个去处，两个名字**。按 label id 比较会把这种最典型的
重复块全部漏掉（早期实现正是这样，手工对比开/关产物「一点变化都没有」）。

做法是先把标签解析成它所在的基本块，再比块号。

### 2.3 只有标签、直接跌到下面的块

相邻的合并点标签会各自成为 leader，于是出现「块里只有标签、没有指令」的块：

```
.L_two_3:          ; 块 5：只有标签
.L_two_1:          ; 块 6：标签 + 真正的代码
    LDR r0, [r6, #8]
    ...
```

跳 `.L_two_3` 与跳 `.L_two_1` 落在同一个地方。`xb_resolve_block()` 因此沿着
「块体为空且只有一个后继」一路走下去，直到遇到有指令的块，再比块号；标签成环则返回 -1
（拒绝合并，不猜）。

## 3. 改写形态

合并一组 `k` 个候选，留 `keep`：

1. 在 `keep` 块体前**插入一条新标签** `IR_LABEL new_label`（`new_label = f->label_count++`）；
2. 每个 `drop` 的块体整体替换成一条 `IR_JMP new_label`；
3. `drop` 块**自己的前导标签原地保留**——它们还是别人的跳转目标，动的只是块体。

因此每合并一个成员净省 `len - 1` 条指令，一组省 `(k-1)*(len-1)`。

## 4. 迭代与终止

与 `ir.tailmerge` 同形：**每轮只合并一组收益最大的**，然后 `mir_build()` 重建 CFG，
重新求深度、重新找候选。每轮至少把 `ARK_XBLOCK_MIN_LEN`（4）条指令压成 1 条，
所以轮数自然有界；`guard <= f->code_count` 只是把「万一写错」从死循环变成退出。

候选组的选择按 `(k-1)*(len-1)` 取最大，平手取最早出现的组，结果不依赖遍历顺序。

## 5. 拒绝清单（一律逐字节不变）

| 形态 | 拒绝原因 |
| --- | --- |
| 以条件分支收尾的块 | §2.1：fall-through 后继由位置决定 |
| 两块块体相同但终结指令指向不同块 | 同一段代码，两个出口 |
| 块体短于 `ARK_XBLOCK_MIN_LEN`（4 条） | 每份副本要付一条入口跳转，短块只亏不赚 |
| 含 `IR_FUNC_BEGIN` / `IR_FUNC_END` | 一个函数只该有一次；顺带把入口块排除在候选之外 |
| 函数里出现内联汇编 / 未知栈效应的指令 / 同一标签被两种深度进入 | 栈模型整函数放弃，半对的 CFG 比不优化更糟 |
| `__naked` / `__asm` 函数 | 不碰手写函数体 |

## 6. 裁切

三层，与既有的 pass 一致：

| 层次 | 手段 | 关掉时的保证 |
| --- | --- | --- |
| 编译期 | `ARKCC_FEATURE_XBLOCK`（STM32_MIN 或无 MIR ⇒ 0） | 代码整块消失；阶段表仍有该行但 `built_in = 0`；`--xblock` 以 `C3900U` 拒绝并点名宏 |
| 运行期 | `--xblock` / `--no-xblock`、INI `xblock=` | 产物与「构建里根本没有这个 pass」逐字节相同 |
| 剖面 | `--pipeline=lite` | 贵阶段被跳过并写明原因 |

共享段（匹配器 + 栈深模型）由 `ARKCC_FEATURE_TAILMERGE || ARKCC_FEATURE_XBLOCK` 包住：
两个宏都为 0 时，这个 `.c` 里没有一行有效代码。

## 7. 判据（`make test-xblock`）

`tests/run_xblock_tests.py`，26 项检查，五个问题各自能单独失败：

1. **静态**：开关开则汇编变；重复块体的**调用点计数**从 5 降到 2（`two()` 2 处、`three()` 3 处）；
   每个共用块前面有新标签；被丢弃的块改为跳向该标签；指令行数与字节数都变小。
2. **拒绝形状逐字节相同**：条件分支块（§2.1）、块体相同但出口不同（`break` 到两个不同退出点）、
   短于下限（`goto` 形态，块体只有一条跳转）、函数含内联汇编；
   另有**同 TU 混合文件**证明「只碰可合并的那个函数」，排除「整个文件没跑过 pass」的假绿。
3. **动态**：同一程序开/关在 ARM 模拟器上返回同值，且值非平凡（`37`）；被拒绝的形状同样同值。
4. **防假绿**：默认关且默认对象逐字节相同；`--no-xblock` 撤销；`-DARKCC_FEATURE_XBLOCK=0`
   构建以 `C3900U` 拒绝且默认对象与完整构建哈希相同；INI `xblock=1` 生效；
   阶段表列出 `--xblock`；`-O0` 下开与不开逐字节相同。
5. **字节账**：构造用例对象 869 → 767 B、汇编指令行 320 → 272。

## 8. 实测与限制

- 构造用例（两个 + 三个相同分支、块体含一次函数调用）：汇编指令行 320 → 272（-15.0%），
  对象 869 → 767 B（-11.7%），`BL g` 5 处 → 2 处。收益完全来自消除重复的调用序列。
- 只在本 TU 的 IR 上工作：跨 TU 需要 `--ipo` 先把函数体拉进来（与 `ir.tailmerge` 同）；
  跨函数共享属于 P5 `cross-call`，**明确不排期**。
- 对已经足够规整的代码收益有限：源里出现重复的表达式序列才有东西可合并，
  CSE 与循环不变量外提会把这类重复先吃掉一部分，因此**只在真正重复的源形状上可见**。
- 门禁只覆盖 ARM 目标的汇编形状；其它后端走同一个 IR pass，等价性由「IR 级别改写 +
  模拟器同值」保证，没有逐后端断言。
